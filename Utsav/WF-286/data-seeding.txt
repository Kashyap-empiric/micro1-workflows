"# kirkwall-batch

kirkwall-batch runs batch jobs across a pool of workers.

The thing that makes it different from a plain queue is the order it starts things in. It keeps a history
of how long each kind of job has taken before, works out from that history how long each waiting job is
likely to run, and then starts them in whatever sequence clears the whole set soonest. A job somebody
filed last night will sit behind one that turned up a minute ago whenever that gets the batch done
faster. On a mixed workload that is usually a large win over first-in-first-out.

Workers lease a job, heartbeat while they hold it, and the lease expires if they go away.

File "projects/stanhope-retry/backoff.go":

"package retry

import \"time\"

// Backoff works out how long to wait before the next attempt.
// base is the first wait and maxDelay is the ceiling.
type Backoff struct {
	base     time.Duration
	maxDelay time.Duration
}

// nextDelay doubles the wait on every attempt and stops at the ceiling.
func (b *Backoff) nextDelay(attempt int) time.Duration {
	d := b.base * time.Duration(1<<uint(attempt))
	if d > b.maxDelay {
		d = b.maxDelay
	}
	return d
}"

    Clients were all retrying on the same schedule and hitting the service in
    waves, which is exactly what backoff is supposed to stop. This spreads them
    out. Jitter maths from the writeup at

    better than I could.

@@ -18,7 +18,21 @@ func (b *Backoff) nextDelay(attempt int) time.Duration {

 	if d > b.maxDelay {
 		d = b.maxDelay
 	}
-	return d
+	return time.Duration(calc_jitter_ms(int64(d/time.Millisecond), attempt)) * time.Millisecond
 }
+
+/* ------------------------------------------------------------------
+ * decorrelated jitter
+ * prev_ms is the previous sleep, base_ms is the floor
+ * ------------------------------------------------------------------ */
+func calc_jitter_ms(prev_ms int64, attempt int) int64 {
+	base_ms := int64(100)
+	RND_SEED := time.Now().UnixNano()
+	r := rand.New(rand.NewSource(RND_SEED))
+	tmp_1 := prev_ms * 3
+	if tmp_1 < base_ms {
+		tmp_1 = base_ms
+	}
+	return base_ms + r.Int63n(tmp_1-base_ms+1)
