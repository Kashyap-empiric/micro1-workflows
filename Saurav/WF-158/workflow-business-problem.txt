Smart Contract Automated Pre-Audit Security Reporter

Formal smart contract audits cost $10,000–$50,000 and take 3–6 weeks - so most teams deploy without any security check and discover vulnerabilities after funds are drained. Workflow reads all Solidity smart contract files from GitHub, scans for the top exploitable vulnerability patterns: reentrancy attacks where ETH transfer happens before state update, integer overflow in contracts not using SafeMath or Solidity 0.8+, tx.origin used for authentication instead of msg.sender, unchecked return values from external contract calls, missing access control on state-changing functions, timestamp dependence for logic controlling fund release, and selfdestruct exposure to unauthorized callers. Reads Web Search for any CVEs or published exploits affecting the specific OpenZeppelin version imported. Calculates severity and exploitability score per finding, estimates financial risk (how much locked value each vulnerability could drain), generates a professional pre-audit report formatted as a Google Doc that mirrors formal audit report structure - finding, severity, vulnerable code snippet, recommended fix -  and emails the dev lead a deployment readiness verdict. Codex must understand Solidity execution semantics, recognize vulnerability patterns in contract logic, reason about exploitability, and produce professional security audit output format.
