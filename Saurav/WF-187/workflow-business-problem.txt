Cross-Platform LLM Prompt Version Drift Tracker

In 2026, every IT company has LLM prompts embedded across their Python backend, MERN frontend, Flutter app, and FlutterFlow project simultaneously - and they all diverge. The system prompt that defines the product's AI persona gets updated in the Python FastAPI service but the Flutter app still has the old version, or a prompt was tuned for GPT-4 performance but the team switched to Claude and nobody re-tuned it for the new model's strengths. Workflow reads all files across GitHub repos containing LLM prompt strings (detects prompt templates by searching for patterns like system:, role: "system", HumanMessage, PromptTemplate), maps every unique prompt by its semantic purpose (user-facing chatbot, internal summarizer, code reviewer, data extractor), detects where the same logical prompt exists in multiple codebases with different wording or different model targets, reads Supabase or Firebase logs to find which prompt version is actually being called in production across platforms, uses Web Search to check the target models' current recommended prompting patterns and whether the team's prompts use deprecated patterns for that model version, generates a weekly prompt drift report showing which platforms have diverged from the canonical prompt and by how much. Codex must understand prompt engineering semantics, detect functionally equivalent prompts with different wording across codebases, and assess model-specific prompt compatibility.
